## 摘要
照片级真实感3D视图能告诉远程操作员机器人身处何处，却无法说明场景中包含什么、每个物体被观测得有多好，也无法说明如何将指向和语音转化为机器人动作。CognitiveReality将机器人的RGB-D流转换为一个实时、语义索引的高斯-TSDF地图，由虚拟现实中的操作员和会使用工具的语言智能体共享。单个建图器二进制程序仅通过配置即可服务于任何平台：它接收来自机器人SLAM、关节运动学、动作捕捉或内联视觉跟踪器的位姿，利用影子跟踪器和关键帧锚定的PnP弥补定位中断，并以2 Hz维护开放词汇的实例身份及每个对象的质量。语音和控制器射线通过经过验证的类型化工具以及操作员确认的机器人动作，与持久场景对象建立关联。在受控的智能体评估中，部署的本地Qwen3-VL-8B路由器达到81.24%的工具精确匹配率，而合并感知重放正确重定向了101个被吸收的对象标识符。在机器人数据上，CognitiveReality比高斯加SDF基线高出2-8 dB；在5-40秒的SLAM中断期间，位姿误差保持在1-8 cm以内。该智能体在两台四足机器人上实时部署，执行了30个导航请求中的26个和20个重新观测请求中的20个，使对象质量提高了2-5 dB。

## Abstract
A photorealistic 3D view tells a teleoperator where a robot is, but not what the scene contains, how well each object has been observed, or how to turn pointing and speech into robot action. CognitiveReality turns a robot's RGB-D stream into a live, semantically indexed Gaussian-TSDF map shared by an operator in virtual reality and a tool-using language agent. One mapper binary serves any platform through configuration alone: it ingests poses from robot SLAM, joint kinematics, motion capture or an inline visual tracker, bridges localization outages with a shadow tracker and keyframe-anchored PnP, and maintains open-vocabulary instance identities with per-object quality at 2 Hz. Speech and controller rays are grounded against persistent scene objects through validated typed tools and operator-confirmed robot actions. In the controlled agent evaluation, the deployed local Qwen3-VL-8B router reaches 81.24\% tool exact match, while merge-aware replay correctly redirects 101 absorbed object identifiers. On robot data CognitiveReality exceeds a Gaussian-plus-SDF baseline by 2-8 dB; pose error through 5-40 s SLAM outages stays within 1-8 cm. Deployed live on two quadrupeds, the agent executed 26 of 30 navigation requests and 20 of 20 re-observation requests, raising object quality by 2-5 dB.

## 1. 核心问题与整体含义
- **研究动机**：传统遥操作界面多依赖平面相机或高质量 3D 重建，但照片级 3D 视图只能回答“机器人在哪”，无法直接回答“场景里有什么”“每个物体观测质量如何”“如何把语音与指点转化为机器人动作”。
- **核心问题**：如何把机器人 RGB-D 流转化为一个**实时、语义索引、可共享**的场景表示，使 VR 操作员与 LLM 智能体能够在同一对象级场景模型上查询、指代、确认并驱动机器人。
- **整体含义**：论文提出 CognitiveReality，将在线 Gaussian-SDF 建图、开放词汇实例语义、版本化 Scene Model、类型化工具智能体与沉浸式 VR 遥操作统一起来，强调“共享场景记忆”而非单纯渲染外观。

## 2. 方法论
- **核心思想**：
  - 用 **Gaussian-TSDF/Gaussian-SDF 混合表示**同时提供几何稳定性与照片级渲染。
  - 用**持久对象 ID + 语义标签 + 重建质量**构建 Scene Model，作为机器人、智能体、操作员之间的统一接口。
  - 将语言/语音/控制器射线解析为**类型化工具调用或机器人任务**，经校验和操作员确认后执行。
- **关键组件与流程**：
  - **在线跟踪与重建**：接收机器人 SLAM、关节运动学、动捕或内联 ORB-SLAM3 位姿；深度融合到 TSDF，Gaussian 由光度误差与几何一致性联合初始化，并异步优化、剪枝。
  - **定位中断恢复**：主定位失效时用影子视觉跟踪器估计到全局地图的变换；二者同时失效时，用最近三个 RGB-D 关键帧做 **PnP-RANSAC** 注册，保持地图连续，不重置全局地图。
  - **Label Splats**：在 SDF 表面加入冻结的纯语义 Gaussian，参与语义身份与中心投票，但不进入光度光栅化，以提升语义覆盖且不损害渲染。
  - **语义 VLM 审计器**：双速率架构，快速跟踪 2–3 Hz，慢速发现 0.5 Hz；本地 VLM 验证掩码、发现新物体，SigLIP + difflib 统一同义词，陈旧类自动退休。新物体约 1–2 s 注册，严格双视图确认时 4–5 s。
  - **Scene Model**：每 2 秒导出 JSON，包含场景尺寸、Gaussian 数量、对象类别/ID、质心、包围盒、重建质量等。
  - **VR 两种模式**：RSIS 主机渲染双目图像并通过 WebRTC 传输；3SLR 主机发送 TSDF 网格与量化 Gaussian，头显本地 OpenXR/OpenGL ES 渲染，仅传输增量。
  - **人-智能体交互**：输入元组 \(x=(u,g,s,h)\)，其中 \(u\) 为语音/文本，\(g\) 为空间 grounding，\(s\) 为场景状态，\(h\) 为历史；输出澄清或类型化决策 \(d=(k,n,a)\)。采用确定性预路由 + schema 约束的本地 Qwen3-VL-8B 路由；后校验检查参数完整性、对象存在性、合并后 ID 与状态一致性。
  - **智能体-机器人交互**：高层目标与机器人执行分离；导航目标需操作员确认，重观测请求与执行结果分离，必须由传感器反馈验证。
