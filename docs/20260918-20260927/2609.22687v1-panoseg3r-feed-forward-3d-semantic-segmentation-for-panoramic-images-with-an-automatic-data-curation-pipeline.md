## Abstract
We present PanoSeg3R, a feed-forward framework for 3D panoramic semantic segmentation. Unlike existing methods designed for perspective inputs, PanoSeg3R jointly predicts 3D geometry and multi-view semantic segmentation in one single forward pass. Built upon a pretrained reconstruction backbone that supports panoramic images, our approach extends feed-forward 3D reconstruction with a query-based mask decoder. Furthermore, we introduce an automatic panorama data curation pipeline that leverages the complementary strengths of off-the-shelf foundation models to generate reliable pseudo semantic annotations, substantially expanding the training data and improving zero-shot generalization. PanoSeg3R achieves state-of-the-art performance on panoramic 3D semantic segmentation, improving 3D mIoU by up to 16.02 on ScanNet++, while the curated training data further improves zero-shot performance by up to 4.26 and 43.28 mIoU on Stanford2D3D and ToF-360, respectively. ## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：3D 场景理解对沉浸式媒体、机器人、自主导航等应用至关重要。近年来基于学习的多视角方法已能同时完成 3D 几何重建与稠密语义预测。
- **痛点一：透视输入的采集效率低**。现有方法依赖透视（perspective）图像，视野有限，需大量重叠观测才能覆盖完整场景，在大规模环境中采集效率低下。
- **痛点二：全景方法无法保证多视角一致**。全向相机以 ERP（等距柱状投影）表示，虽单视角信息更丰富，但现有全景语义分割方法（畸变感知网络、多任务框架等）只处理单张 ERP 图，**无法产生多视角一致的语义分割**。
- **痛点三：前馈方法不原生支持全景**。PanSt3R、IGGT、Uni3R 等前馈方法面向无畸变透视图像设计，处理全景须先转 cubemap / 切平面投影，既增加计算开销，又损害跨视角几何与语义一致性。
- **痛点四：全景标注数据稀缺**。全景逐像素标注成本高、劳动密集，难以构建大规模标注数据集。
- **整体含义**：论文提出 **PanoSeg3R**——据作者所述，**首个无需 ERP-to-perspective 投影即可完成 3D 语义分割的方法**，单次前向即可从多视角 ERP 图直接预测稠密 3D 语义；并配套自动数据策管流水线缓解标注稀缺问题。

## 2. 方法论

### 2.1 核心思想
- 基于预训练的全景重建骨干 **Wid3R**（宽视场 3D 重建，用相机射线表示像素、球谐编码射线方向，对全景畸变鲁棒），扩展出**基于查询（query-based）的掩码解码器**，一次前向同时输出几何与多视角语义。
- 用冻结的 **SigLIP 文本编码器**表示类别名，使不同类别体系的多个数据集可在共享嵌入空间中联合训练。

### 2.2 全景特征与几何提取
- 多视角 ERP 图 $\{I_i\}$ 经 Wid3R 编码为图像 token 序列 $T_i^{(0)} \in \mathbb{R}^{K \times d_T}$，经交替的帧内 / 全局注意力层得到 $T_i^{(l)}$。
- 每个全景预测射线方向图 $R_i$ 与径向距离图 $D_i$，点图 $P_i = R_i \odot D_i$。

### 2.3 语义掩码预测与分类
- **查询精炼**：$N_q$ 个跨视角共享的可学习语义查询 $Q_n^{(0)}$，经与最后一层 token $T^{(L)}$ 的交叉注意 + 自注意解码，得 $\hat{Q}_n$。
- **语义分类**：类别名经 SigLIP 编码为 $\{t_j\}$；查询经线性头投影为 $q^{\text{cls}}_n$，分类分数为余弦相似度 $p_{n,j}=\text{sim}(q^{\text{cls}}_n, t_j)$。
- **语义掩码**：DPT 头聚合多尺度 token $\{T^{(l)}\}$，得到稠密特征图 $F_i \in \mathbb{R}^{d_F \times \frac{H}{2}\times\frac{W}{2}}$。
- **低层特征注入（image stem）**：因 ERP 中每个 patch token 覆盖的视场远大于透视图像，细粒度空间细节在 token 化时丢失；故用一条 stem 支路（strided 卷积 + 残差卷积块 + 1×1 投影）提取低层特征 $S_i$，**所有卷积均采用 circular padding 以保持 ERP 水平连续性**。融合后经投影头 $H$ 得 $\tilde{F}_i = H(F_i + S_i)$。
- **掩码输出**：$M_{n,i} = \text{Sigmoid}\big((q^{\text{mask}}_n)^\top \tilde{F}_i\big)$，其中 $q^{\text{mask}}_n = \text{MLP}_{\text{mask}}(\hat{Q}_n)$。
- **损失**：沿用 Mask2Former 形式，$\mathcal{L} = \lambda_c \mathcal{L}_{\text{cls}} + \lambda_d \mathcal{L}_{\text{dice}} + \lambda_b \mathcal{L}_{\text{bce}}$。

### 2.4 自动语义全景数据策管流水线（四阶段）
1. **预处理**：将 ERP 图投影为 5 张无畸变透视图（方位角间隔 72°，覆盖 360°），每张再切为上/中/下 3 个 crop，共 **15 个 crop**（尺寸 $c_h \times c_w$，水平/垂直重叠 $o_h, o_v$），以降低 ERP 畸变对基础模型的影响。
2. **掩码生成**：**SAM3** 直接在 ERP 上生成类无关掩码（边界精确但无语义）；**PanSt3R** 在 15 个 crop 上生成 panoptic 预测，丢弃实例 ID，保留语义（词表为 ScanNet++ 的 100 类）。
3. **掩码聚合**：将 crop 级 PanSt3R 区域重投影 / splat 回 ERP 空间得 $\widetilde{er}_i$；对每个 SAM3 掩码 $m_k$ 计算 IoU $A_{k,i}=\text{IoU}(m_k, \widetilde{er}_i)$，超过阈值 $\tau_{\text{IoU}}$ 视为有效匹配，取 IoU 最大的区域标签赋给该掩码；无有效匹配则保持未标注。
4. **VLM 过滤**：以 **Qwen3-VL-8B** 对每个已标注掩码裁剪局部 RGB 区域并将目标轮廓标红，用链式思维提示（先识别物体、再判断标签是否合理、最后回答 Correct/Incorrect）剔除不一致标注，保留正确者形成最终标注。

### 3.2 Benchmark 与评测协议
- **2D 指标**：语义预测缩放至

分辨率并与真值对齐，报告 **mIoU**（主指标）与 **mAcc**；由于各数据集类别体系不同，均在各自数据集内部独立评测，不跨数据集合并类别。
- **3D 指标**：将 2D 语义按预测几何反投影至 3D 点云，报告 **3D mIoU** 与 **3D mAcc**，衡量几何—语义联合质量。
- **评测模式**：区分**类内（in-domain）**与**跨数据集/零样本（cross-dataset）**两种设定；后者仅用其他数据集训练、在目标数据集直接测试，用以考察文本嵌入分类头带来的开放词表泛化能力。
- **对比基线**：单视角全景分割方法（如畸变感知分割网络）逐视角预测后拼接、PanSt3R + 2D 分割后处理、以及若干前馈 3D 重建 + 语义方法；所有基线在相同输入视角数与分辨率下比较。

## 4. 主要实验结果

- **在域性能**：PanoSeg3R 在 ScanNet++、Matterport3D、Stanford2D3D、ToF-360 上均取得最优或可比 2D/3D 语义分割指标，且**单次前向**即可完成，无需逐视角独立推理或后处理融合。
- **跨数据集泛化**：借助冻结 SigLIP 文本编码器构建的共享语义嵌入空间，模型在未参与训练的数据集上表现出明显优于闭集分类基线的零样本迁移能力，验证文本对齐分类头对多类别体系联合训练的有效性。
- **一致性优势**：得益于在 ERP 原生表示上做多视角联合推理，跨视角语义标签的一致性显著优于"逐视角分割 + 拼接"类基线，尤其在全景图像接缝（左右边界）与极区附近。
- **数据策管有效性**：使用自动流水线生成的伪标签（Realsee3D、OmniScenes）参与训练，可稳定提升在真实标注数据集上的表现，说明流水线产出的标注噪声可控、覆盖面广。

## 5. 消融与深入分析

- **低层特征注入（image stem）**：移除 stem 支路后边界细节与小物体分割明显退化，验证 ERP 中单个 token 感受野过大导致的细节丢失问题确实存在且被该设计缓解。
- **circular padding**：将卷积填充改为零填充后，ERP 左右接缝处出现语义断裂，证明保持水平周期连续性的必要性。
- **骨干选择**：替换为面向透视图像的前馈重建骨干（需先做 cubemap 投影）会同时降低几何精度与语义一致性，佐证"原生全景处理"的核心论点。
- **数据策管各阶段**：逐步加入 SAM3 掩码、PanSt3R 语义、VLM 过滤，标注质量与下游性能单调提升；其中 VLM 过滤对剔除错误标签贡献最大。
- **IoU 阈值 $\tau_{\text{IoU}}$ 敏感性**：过低引入错误匹配、过高导致大量掩码未标注，实验中取中间值最优。
- **类别名嵌入 vs. 可学习分类头**：文本嵌入在类内性能略降但跨数据集泛化大幅提升，体现精度与开放性的权衡。

## 6. 贡献总结

1. 提出 **PanoSeg3R**，据作者称为**首个无需 ERP-to-perspective 投影、单次前向即可从多视角 ERP 图直接输出稠密 3D 语义**的方法，将全景重建骨干扩展为查询式掩码解码器，统一几何与语义。
2. 设计**低层特征注入 + circular padding** 的细节补偿机制，针对 ERP token 化造成的空间细节损失提出针对性解决方案。
3. 引入**冻结 SigLIP 文本编码器**作为类别表示，实现多类别体系数据集的联合训练与零样本跨数据集迁移。
4. 构建**四阶段自动语义全景数据策管流水线**（SAM3 类无关掩码 + PanSt3R 语义 + 重投影聚合 + VLM 链式思维过滤），在无人工标注条件下扩展训练数据规模，缓解全景标注稀缺问题。

## 7. 局限与展望

- 伪标签质量仍受基础模型（SAM3、PanSt3R、Qwen3-VL）能力上限约束，细长结构与罕见类别易漏标或错标。
- 评测类别体系仍以室内数据集为主，大规模室外 / 动态全景场景的适用性有待验证。
- 依赖预训练全景骨干 Wid3R，骨干能力成为整体性能的瓶颈之一。
- 未来方向可包括：端到端弱监督训练、动态时序全景语义、以及更高效的 token 化以进一步降低高分辨率 ERP 的计算开销。
