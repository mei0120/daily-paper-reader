## 摘要
开放词汇3D地图使机器人能够利用自然语言对先前未知环境进行推理。然而，现有系统通常对每张输入图像进行分割，将检测结果与持久3D片段关联，并频繁执行昂贵的视觉-语言（VL）推理。我们提出 TRACKGRAPH，一种在线开放词汇系统，在将片段融合到3D之前，直接在图像流中保持短期2D掩码身份。FastSAM 掩码和 CLIP 特征在稀疏关键帧上计算，而密集的 DINOv3 特征用于在关键帧之间以高频率传播掩码。得到的跟踪掩码被融合到分层场景图中的类别无关3D片段层，并通过3D关联处理跟踪中断和长期重访。紧凑的多视图 CLIP 嵌入支持开放词汇检索。在 Replica、ScanNet++ 和 HM3D 上，TRACKGRAPH 在开放词汇分割和检索方面与最先进的建图方法相比具有竞争力，包括在 Replica 上取得最高的同义词频率（0.50）。在相同的 NVIDIA A100 上，它比 ViT-H OVI-MAP 快 1.7 倍，GPU 内存占用少 3.3 倍。真实世界四足机器人部署展示了机载场景图构建和以 7.5Hz 进行目标搜索，同时使用记录的无人机数据在航拍视角下测试该方法。

## Abstract
Open-vocabulary 3D maps enable robots to reason about previously unknown environments using natural language. However, existing systems typically segment every incoming image, associate detections with persistent 3D segments, and frequently perform costly Vision-Language (VL) inference. We present TRACKGRAPH, an online open-vocabulary system that maintains short-term 2D mask identity directly in the image stream before fusing segments into 3D. FastSAM masks and CLIP features are computed at sparse keyframes, while dense DINOv3 features are used to propagate masks at a high rate in between. The resulting tracked masks are fused into a class-agnostic 3D segment layer within a hierarchical scene graph, with 3D association handling tracking interruptions and long-term revisits. Compact multi-view CLIP embeddings enable open-vocabulary retrieval. Across Replica, ScanNet++, and HM3D, TRACKGRAPH achieves competitive open-vocabulary segmentation and retrieval against state-of-the-art mapping methods, including the highest synonym frequency on Replica (0.50). On the same NVIDIA A100, it is 1.7x faster and uses 3.3x less GPU memory than ViT-H OVI-MAP. Real-world quadruped deployments demonstrate onboard scene graph construction and object search at 7.5Hz, while recorded drone data is used to test the method under aerial viewpoints.

## 1. 核心问题与整体含义

- **研究动机**：开放词汇3D地图使机器人能用自然语言推理未知环境，但现有系统通常逐帧分割图像、将检测结果与持久3D片段关联，并频繁执行昂贵的视觉-语言（VL）推理，导致在线机器人难以承受计算与显存开销。
- **核心问题**：如何在机器人探索过程中，以在线、低开销的方式构建开放词汇3D场景图，同时保持物体级身份一致性，并支持语言/图像检索与导航。
- **整体含义**：TRACKGRAPH 提出“先在图像空间维持短期2D掩码身份，再融合为3D片段”的思路，把3D关联推迟到跟踪中断或长期重访时处理，从而减少重复分割与VL推理，实现在线开放词汇建图与目标搜索。

## 2. 方法论

### 2.1 核心思想

- 使用 Hydra 作为在线重建与场景图骨干，但将其物体层替换为**类别无关的3D片段层**。
- 在稀疏关键帧上运行 FastSAM 分割和 CLIP 特征提取；在关键帧之间用稠密 DINOv3 特征传播掩码身份。
- 每个时间上持续的2D掩码身份称为 **source track**。source track 被持续融合进 TSDF 与 mesh，再构建持久3D片段。
- 仅在跟踪中断或长期重访时，才通过3D几何与视觉关联进行合并与重识别。

### 2.2 关键技术细节与流程

- **场景图表示**：图节点分为 mesh、3D片段、place、room、building 等层。mesh 顶点存储最多 K 个 source track 假设及权重；3D片段节点包含包围盒、质心、source track 集合、聚合 DINOv3 特征、CLIP 特征画廊及 active/historical 状态。TSDF 与 mesh 在当前位置周围 8 m 活动窗口内重建。
- **实例跟踪前端**：
  - 每帧提取 DINOv3 ViT-S+ 特征图。
  - 每 Kf 帧（主实验 Kf=24）运行 FastSAM 得到类别无关掩码，并异步计算 CLIP 特征。
  - 关键帧之间，将 DINOv3 patch 的 source track 概率分布按相似 patch 传播：  
    \(Y_t(p)=\sum_{(q,r)\in K_t(p)} a_{pqr} Y_r(q)\)，其中 \(a_{pqr}\) 为 softmax 归一化后的 DINOv3 相似度。
  - 关键帧校正：将 FastSAM 掩码与传播掩码按 IoU 和 DINOv3 特征相似度匹配，得分  
    \(s_{ij}=w_{IoU}\mathrm{IoU}+w_{feat}\max(\cos,0)\)，再贪心一对一关联。匹配则延续 track，未匹配检测新建 track，未匹配活动 track 退休。
  - CLIP 特征按 track 做增量平均：\(f_i^{ov}\leftarrow (n_i^{ov}f_i^{ov}+f_{t_k,j}^{ov})/(n_i^{ov}+1)\)。
- **融合到3D**：每个 TSDF 体素最多存 K=4 个 source track 假设。若投影体素落在某 track 掩码内，则更新权重  
  \(\ell_{v,\tau_i}=\ell_{v,\tau_i}+w_{TSDF}\gamma_t(\tau_i)\)。传播掩码置信度随时间衰减：关键帧掩码为1，传播掩码为 \(\alpha_p/(1+\beta_p\Delta t)\)。Marching Cubes 提取 mesh 后，顶点继承体素假设集。
- **3D片段更新器**：按 mesh 顶点的获胜 track 身份分组。新 track 若未分配片段，则与现有活动片段比较双向顶点重叠率  
  \(\rho_{q\to i}=|V_q\cap V_i|/|V_q|\)，\(\rho_{i\to q}=|V_q\cap V_i|/|V_i|\)，并要求 DINOv3 相似度超过阈值。满足条件则合并到已有片段，否则新建片段。
- **长期重识别**：对历史片段质心建 k-d 树。查询片段与历史候选计算几何重叠  
  \(o_{qh}=|\{x\in S_q|\min_{y\in S_h}\|x-y\|_2\le r_{nn}\}|/|S_q|\)，再与 DINOv3 特征余弦相似度结合：  
  \(J_{qh}=\lambda_o o_{qh}+\lambda_a \cos(f_q^{DINO},f_h^{DINO})\)。通过阈值后合并到历史节点，历史节点重新激活。
- **开放词汇画廊与查询**：每个3D片段保存按 source track 组织的 CLIP 特征画廊，不把多视图平均成单一特征。查询时取画廊中最大余弦相似度：  
  \(s_i(q)=\max_{(\tau,f_\tau^{ov})\in F_i^{ov}} \frac{q\cdot f_\tau^{ov}}{\|q\|\|f_\tau^{ov}\|}\)，返回排序后的片段节点。
