## 摘要
无需训练的加权聚合被广泛用于将二维语义特征提升到三维高斯上，以支持开放词汇场景理解，但其理论作用仍未得到充分理解。现有分析通常从渲染角度证明该操作的合理性，将高斯特征视为可线性组合的欧几里得变量，用于重建二维特征图。然而，这种观点与下游三维使用方式并不匹配，因为在三维使用中，每个高斯通常会在基于余弦的嵌入空间中独立查询。我们重新从三维角度审视特征提升，并将逐高斯分配形式化为CLIP单位球面上的余弦对齐问题。在该目标下，L2归一化后的语义反投影特征作为闭式解出现，从而从逐高斯语义分配的角度为标准提升规则提供了补充性解释。同一形式化还进一步给出一种范数分解，将其分解为视图内一致性与视图间一致性，这表明特征幅值本身可以作为一种语义可靠性信号。经有效的多视图支持校准后，该可靠性分数引导一种模式投票式细化，通过避免线性平均来保持CLIP特征的有效性。在开放词汇三维语义分割上的实验表明，NormLift是一种高效、无需训练的框架，在多种评估协议下均取得强劲性能。

## Abstract
Training-free weighted aggregation is widely used to lift 2D semantic features onto 3D Gaussians for open-vocabulary scene understanding, yet its theoretical role remains insufficiently understood. Existing analyses typically justify this operation from the rendering side, treating Gaussian features as linearly composable Euclidean variables for reconstructing 2D feature maps. However, this view does not match downstream 3D usage, where each Gaussian is often queried independently in a cosine-based embedding space. We revisit feature lifting from the 3D side and formulate per-Gaussian assignment as a cosine alignment problem on the CLIP unit sphere. Under this objective, the L2-normalized semantic back-projected feature emerges as the closed-form solution, providing a complementary interpretation of the standard lifting rule from the perspective of per-Gaussian semantic assignment. The same formulation further yields a norm decomposition into intra-view and inter-view consistency, suggesting that feature magnitude itself can serve as a semantic reliability signal. Calibrated by effective multi-view support, this reliability score guides a mode-voting refinement that preserves CLIP feature validity by avoiding linear averaging. Experiments on open-vocabulary 3D semantic segmentation show that NormLift is an efficient, training-free framework that achieves strong performance across evaluation protocols.

- **整体含义**：论文将逐高斯特征提升重新形式化为CLIP单位球面上的余弦对齐问题，证明标准的"反投影 + L2归一化"恰好是该3D侧目标的闭式最优解，并由此导出可作为语义可靠性信号的范数分解，最终构建一个免训练、高效的开放词汇3D语义分割框架。

## 2. 方法论：核心思想与关键技术细节

### 2.1 CLIP特征的三个几何性质（分析基础）

- **性质1（球面约束）**：CLIP特征位于单位超球面上，因为图像和文本编码器在对比学习前都做了L2归一化，任何用于查询的提升特征必须满足模长为1。
- **性质2（方向语义）**：CLIP以余弦目标训练，语义相似度由余弦而非欧氏距离度量。
- **性质3（语义流形非线性）**：CLIP语义流形对线性组合不封闭，两个语义距离较远特征的线性混合会产生"语义漂移"（论文用门与沙发的混合实验显示，在α∈[0.3,0.7]区间预测类别漂移到无关类别，整体漂移率33.6%）。

### 2.2 逐高斯余弦对齐问题（核心形式化）

- 对每个高斯 $j$，定义单位特征 $u_j$ 的目标函数：在CLIP单位球面上最大化其与所有支撑2D观测 $B_i$ 的加权余弦一致性，权重为alpha混合贡献 $A_{ij}$。
- 由内积线性性，目标可改写为 $\max_{\|u\|=1}\langle u, f_j\rangle$，其中 $f_j$ 即标准的反投影特征（加权平均）。
- 由Cauchy–Schwarz不等式，当 $f_j \neq 0$ 时闭式解为 $u_j^\star = f_j / \|f_j\|$，最优值为 $\|f_j\|$；边界情形 $f_j=0$ 对应"空证据"退化情形。
- **关键意义**：标准的"反投影 + L2归一化"不是后处理启发式，而是逐高斯语义一致性目标的闭式最优解；L2归一化由目标本身处理，而非事后步骤。

### 2.3 范数分解与语义可靠性分数

- **范数分解（代数恒等式）**：$\|f_j\|$ 可分解为两个 $[0,1]$ 区间因子之积：
  - $C_{\text{intra}}(j)$：**视图内一致性**（within-view concentration），当单视图给高斯混合语义方向时下降；
  - $C_{\text{inter}}(j)$：**视图间一致性**，通过各视图方向的加权平均合向量长度度量跨视图一致性。
- 因此 $\|f_j\|$ 高当且仅当支撑观测在视图内与视图间都一致，是语义一致性的结构性指标。
- **有效视图校准**：单一主导视图仍可能产生高范数，故引入经典有效样本量 $N_{\text{eff}}(j)$（权重均匀时趋近可见视图数，单视图主导时为1），定义可靠性分数：
  - $R(j) = \|f_j\| \cdot \frac{N_{\text{eff}}(j)}{N_{\text{eff}}(j)+\beta}$，其中 $\beta=1$ 作为贝叶斯均值收缩的先验强度。

### 2.4 可靠性引导的KNN模式投票细化

- **动机**：CLIP语义流形的非线性（性质3）意味着对邻居CLIP特征做线性平均会偏离流形，因此细化应"复制"一个连贯方向而非混合。
- **邻居模式选择**：对每个高斯 $i$，从其K近邻加自身构成候选集；每个候选 $j$ 获得一个可靠性加权支持分 $S_{ij}$，该分数综合了邻居可靠性 $R(k)$、空间衰减 $d_{ik}$ 与软语义一致性门 $g_{jk}$ 的投票。
- **保守替换**：仅当最佳邻居的支持分超过自身支持分一个边际 $\Delta$ 时才替换 $u_i^\star \leftarrow u_{j^\star}^\star$，否则保留原特征。
- 由于每个细化后的特征都是已存在的 $u_k^\star$，该过程天然保持在单位球面上，绝不通过线性组合构造CLIP方向。

## 6. 主要结论与发现

- 标准"反投影 + L2归一化"是逐高斯CLIP球面余弦对齐目标的**闭式最优解**，提供了不同于渲染侧的3D侧解释。
- 反投影特征的**范数本身**可代数分解为视图内与视图间一致性，经有效多视图支持校准后成为逐高斯语义可靠性分数 $R(j)$。
- $R(j)$ 在零证据边界外与不透明度**基本独立**（Spearman ρ=0.002，p=0.31；Kendall τ≈2×10⁻⁴；最低20%排序的Jaccard重叠0.162，低于独立性基线0.20），提供了不透明度/可见性启发式之外的互补信号。
- 零证据子集 $G_0$（约15.94%的高斯）平均不透明度仅0.042、平均可见计数0.112、下游准确率35.61%，与其余高斯（0.731、11.86、46.21%）形成鲜明对比。
- 可靠性引导的模式投票细化在ScanNet上持续优于免训练与训练型基线，且后提升阶段比SFS快6.7×、端到端快2.0×，显存相当。
- 方法可迁移至2D渲染协议（LERF-OVS），取得最佳平均定位精度。

## 7. 优点

- **理论贡献清晰**：从3D侧重新形式化一个被广泛使用但理论不清的操作，证明标准规则是余弦对齐目标的闭式解，视角新颖且与下游使用方式一致。
- **信号来源内蕴**：可靠性分数 $R(j)$ 直接从同一提升公式代数导出，而非依赖外部可见性启发式或额外网络，方向 $u_j^\star$ 与可靠性 $R(j)$ 是同一目标的两个输出。
- **尊重CLIP流形几何**：模式投票细化复制单个连贯方向而非线性平均，从构造上保持在单位球面上，避免了论文用实验证明的语义漂移问题。
- **免训练且高效**：无需梯度语义优化，后提升阶段比SFS快6.7×，端到端快2.0×，显存相当，实用性强。
- **实验分析细致**：可靠性-不透明度关系分析、零证据子集刻画、范数分解验证、超参数敏感性分析等，对方法行为解释充分。
- **保守替换机制**：边际条件 $\Delta$ 防止在邻域证据仅微弱更强时覆盖特征，提升稳健性。

## 8. 不足与局限

论文自述的局限：

- **几何依赖**：框架将alpha混合权重 $A_{ij}$ 与底层3DGS几何作为固定输入，重建中的几何伪影会传播到特征提升。
- **CLIP固有局限**：提升特征继承CLIP在细粒度类别、组合概念及训练分布外对象上的不足。
- **场景覆盖有限**：3D评估仅限ScanNet室内场景，对建筑级、室外或动态场景的泛化性尚待验证。
- **细化依赖可靠邻居**：模式投票要求不可靠高斯的空间邻居中至少有一些本身可靠；系统性不可靠邻域无法仅凭自身恢复，需主动视角规划等额外线索。

可进一步补充的审慎观察：

- 2D评估（LERF-OVS）中mIoU/mAcc并非全面最优（如Ramen场景mIoU 0.287低于Occam's 0.369），说明方法在2D渲染协议下优势有限，其核心收益主要体现在独立查询的3D协议。
- 可靠性分数与不透明度"基本独立"的结论基于特定数据集（ScanNet 10场景），跨数据集的普适性仍需更多验证。
- 训练型基线（如LUDVIG、THGS）的对比主要引用其论文报告值，未在完全统一条件下复现，存在一定比较偏差风险。
- 超参数虽显示不敏感，但6个超参数（β、K、σ_d、τ、γ、Δ）仍需设定，未讨论在分布外场景下的默认值是否依然合适。
