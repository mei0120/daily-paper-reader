## 摘要
开放词汇场景理解是机器人学的基础，为空间推理和物体操作奠定基础。尽管闭词汇3D实例分割大量利用3D形状信息，但最先进的开放词汇方法在掩码标注阶段仍主要局限于2D图像特征或图像蒸馏表示。本文提出SenseFuse，一种无标签融合方法，平衡2D图像与3D形状编码器，以实现稳健的开放词汇3D实例分割，仅对现有流程的掩码标注阶段进行改进。我们发现，2D图像编码器与3D形状编码器表现出很大程度上不相交的失败模式，且很少共享相同的错误标签，而两个2D图像编码器则经常重复相同的错误。这种独特行为使2D与3D的组合具有内在互补性。我们引入一种自适应机制，选择场景级融合权重以最大化一种无标签敏感度度量，该度量可直接从单个场景的无标签提议中在毫秒级估计得到。SenseFuse在ScanNet200、Replica和ScanNet++的每个评估设置中均提升了标注准确率，恢复了使用oracle权重可获得的增益的67–100%（中位数93%），并在22个报告设置中的21个上提升了实例AP。代码可在 https://github.com/hanes1207/SenseFuse 获取。

## Abstract
Open-vocabulary scene understanding is fundamental for robotics, laying the groundwork for spatial reasoning and object manipulation. While closed-vocabulary 3D instance segmentation heavily leverages 3D shape information, state-of-the-art open-vocabulary methods remain predominantly restricted to 2D image features or image-distilled representations during mask labeling. In this paper, we propose SenseFuse, a label-free fusion method that balances 2D image and 3D shape encoders for robust open-vocabulary 3D instance segmentation, refining only the mask-labeling stage of existing pipelines. We reveal that 2D image and 3D shape encoders exhibit largely disjoint failure patterns and rarely share identical wrong labels, whereas two 2D image encoders frequently repeat the same errors. This distinct behavior makes the 2D and 3D pair inherently complementary. We introduce an adaptive mechanism that selects a scene-level fusion weight to maximize a label-free sensitivity measure, estimated directly from a single scene's unlabeled proposals in milliseconds. SenseFuse improves labeling accuracy in every evaluated setting across ScanNet200, Replica, and ScanNet++, recovering 67-100% (median 93%) of the gain achievable with an oracle weight, and it raises instance AP in 21 of 22 reported settings. Code is available at https://github.com/hanes1207/SenseFuse.

## 1. 核心问题与整体含义

- **研究背景**：开放词汇场景理解是机器人学的基础能力，支撑空间推理与物体操作等下游任务。闭词汇 3D 实例分割（3DIS）方法大量利用显式 3D 形状信息，但受限于固定类别集，无法识别新类别。
- **核心痛点**：现有开放词汇 3DIS 方法在**掩码标注阶段**几乎完全依赖 2D 图像编码器或图像蒸馏表示，而原生 3D 形状证据被完全闲置。这导致在深度/遮挡主导的场景中出现关键失败（如被桌子遮挡的椅子被误判为桌子）。
- **关键障碍**：在 2D 伪标签上训练 3D 网络会使其严重偏向已见类别，因此无法通过训练方式引入 3D 形状信息。
- **核心洞察**：实证发现 **2D 图像编码器与 3D 形状编码器的失败模式高度不相交，且极少共享相同的错误标签**（2D–3D 对相同错误率仅 5.9%，而两个 2D 编码器间高达 41.4%）。因此 2D–3D 组合具有内在互补性，是比"再引入一个 2D 编码器"更有利的融合目标。
- **整体含义**：提出一种**免训练、免标签、即插即用**的融合模块，仅改进现有流程的掩码标注阶段，使机器人进入未知环境时无需额外监督即可重新校准实例标签。

## 2. 方法论

### 核心思想
将冻结的 2D 图像编码器与冻结的 3D 形状编码器在**场景级别**用单一标量权重 `w` 进行线性融合，权重通过最大化一种**无标签敏感度度量**自适应选择。该度量可从单个场景的无标签提议中在毫秒级估计得到。

### 关键技术细节

- **问题形式化**：继承现有流程（Open-YOLO3D / OpenMask3D / Open3DIS）的二值掩码 `Mq` 与 2D 图像嵌入 `z2`，并通过冻结的 3D 形状编码器对掩码点云 `Pq` 生成 3D 形状嵌入 `z3`。掩码点重采样至 `N0=10⁴` 点，居中并缩放至单位球。
- **行中心化**：由于两个编码器投影到不同的文本对齐空间，原始余弦分数不可直接比较，故对每个掩码的 K 个分数减去其均值进行中心化：`S^q_{h,c} = s^q_{h,c} − (1/K)Σ s^q_{h,c'}`。
- **敏感度定义**：借鉴信号检测理论的判别指数 `d'_h = μ_h / σ_h`，其中 `μ_h` 为正确类相对背景的平均抬升，`σ_h` 为背景（错误类）分数标准差，均按场景共享近似。
- **线性融合**：`S^q_c(w) = (1−w)S^q_{2,c} + wS^q_{3,c}`，最终标签为 argmax。
- **闭式最优权重**：假设两头部背景分数不相关，融合后敏感度为 `d'_w = [(1−w)μ2 + wμ3] / √[(1−w)²σ2² + w²σ3²]`，令其导数为零得
  `w_law = (μ3/σ3²) / (μ2/σ2² + μ3/σ3²)`。
  令 `π_h = μ_h/σ_h²`，则 `w_law = π3/(π2+π3)`，天然落在 [0,1]。该规则在 Gaussian 分数模型下与 LDA 及均匀先验下的贝叶斯最优决策一致。
- **无标签估计（算法 1）**：由于真实标签未知，用当前融合分数计算的**软责任度**替代标签并迭代：
  - 软类别责任度 `P^q_c = softmax(S^q_c(w)/(τ0·ν_q))`，`ν_q` 为掩码内融合分数的离散度；
  - 背景分布 `Γ^q_c = (1−P^q_c)/(K−1)`；
  - 掩码子集权重 `g_q ∝ [1+e^{−β·m̃_q}]^{−1}`（`m̃_q` 为标准化后的 top-1/top-2 间隔），提供平滑的子集选择；
  - 用责任度加权的矩估计更新 `(μ̂_h, σ̂_h)`，再由公式 (5) 重算 `w`，形成迭代闭环。
  - 超参数 `τ0=0.25`、`β=8` 为无量纲量，对所有数据集和流程通用；最多 12 次迭代，容差 1e-3。
- **收敛性**：软化更新对 `w` 连续且将 [0,1] 映射到自身，由中值定理保证不动点存在；实测从任意初始化均收敛到相同数据集级权重。

## 6. 主要结论与发现

- SenseFuse 在**所有 11 个评估设置中均提升标注准确率**，中位数 +7.1 个百分点（范围 +3.8 至 +25.1）。
- 无标签权重恢复 oracle 增益的**中位数 93%（最低 67%）**；在 22 个 AP 设置中的 21 个提升，最高 +4.5 mAP。
- 权重估计平均每场景 3.5 ms，且 `ŵ` 落在宽泛的准确率平台上（距峰值 1 pp 内的区域跨 0.06–0.27）。
- **类别差异**：几何特征明显的类别增益最大（如浴室隔间门 +62 pp、淋浴墙 +30 pp）；依赖纹理/上下文的小物体退化（如纸巾盒 −22 pp）。退化集中在最低点云数量四分位（−2.1 pp），小掩码（<1000 点）占 ScanNet200 的 28% 但仅占 ScanNet++ 的 0.7%，这解释了 ScanNet++ 增益更高。
- **融合机制验证**：2D–3D 对的相同错误率仅 5.9%，秩相关 ρ ∈ [0.079, 0.226]；而 2D–2D 对相同错误率 41.4%，ρ = 0.677。虽 Uni3D 独立精度（16.1%）远低于 CLIP（41.1%），但与 EVA 融合增益（+4.5）远超 CLIP（+1.2），证明互补性比单头强度更关键。
- **规则对比**：最佳分数级替代方案 PoE 仅差 0.2 pp；决策级路由损失 1.2–1.6 pp，证明**在 argmax 之前融合分数是必要的**。
- **相关性校正无效**：显式校正跨模态背景相关性未能提升准确率，反而可能产生不可容许权重（3%–20% 场景）。

## 7. 优点

- **理论严谨**：基于信号检测理论与 LDA 推导出闭式最优权重，在 Gaussian 假设下与贝叶斯最优决策一致；软化 EM 迭代有不动点存在性证明。

- **即插即用**：与三种主流流程（Open-YOLO3D / OpenMask3D / Open3DIS）兼容，仅替换标注阶段。
