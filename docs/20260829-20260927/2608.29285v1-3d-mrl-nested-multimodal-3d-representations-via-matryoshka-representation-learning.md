## 摘要
视觉-语言模型将点云与图像和文本嵌入对齐，从而支持3D形状的零样本识别、检索和开放词汇理解。现有多模态3D预训练方法产生固定维度嵌入，需要为不同计算预算分别构建模型。我们提出3D Matryoshka表示学习（3D-MRL），一种基于Matryoshka表示学习的多模态3D预训练框架。3D-MRL通过将点云与冻结的CLIP图像和文本嵌入对齐，同时在多个嵌入维度上施加对比监督，来学习嵌套的3D表示。Matryoshka目标仅应用于3D编码器，使单个模型无需重新训练即可生成不同维度的表示。在Objaverse-LVIS、ModelNet40和ScanNet数据集上的实验表明，3D-MRL在零样本和少样本3D识别任务上取得了有竞争力的性能。此外，学习到的表示支持在单个模型内跨不同嵌入维度进行检索。在Objaverse-LVIS上，3D-MRL将Top-1准确率从46.8%提升至50.9%。检索实验进一步表明，不同嵌入维度会产生不同程度的语义与几何特异性。

## Abstract
Vision-Language Models align point clouds with image and text embeddings, enabling zero-shot recognition, retrieval, and open-vocabulary understanding of 3D shapes. Existing multimodal 3D pre-training methods produce fixed-dimensional embeddings, requiring separate models for different computational budgets. We propose 3D Matryoshka Representation Learning (3D-MRL), a multimodal 3D pre-training framework based on Matryoshka Representation Learning. 3D-MRL learns nested 3D representations by aligning point clouds with frozen CLIP image and text embeddings while applying contrastive supervision across multiple embedding dimensions. The Matryoshka objective is applied only to the 3D encoder, allowing a single model to produce representations at different dimensionalities without retraining. Experiments on the Objaverse-LVIS, ModelNet40, and ScanNet datasets show that 3D-MRL achieves competitive performance on zero-shot and few-shot 3D recognition tasks. In addition, the learned representations support retrieval across different embedding dimensions within a single model. On Objaverse-LVIS, 3D-MRL improves Top-1 accuracy from 46.8% to 50.9%. Retrieval experiments further show that different embedding dimensions yield varying levels of semantic and geometric specificity.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：以 CLIP 为代表的视觉-语言模型建立了图文共享嵌入空间；ULIP、OpenShape、Uni3D 等方法将点云映射进该空间，实现零样本分类、开放词汇检索与跨模态 3D 理解。
- **核心痛点**：现有多模态 3D 预训练方法（ULIP、OpenShape、TAMM、MixCon3D、DuoduoCLIP 等）都只学习**单一固定维度**嵌入（通常 512–1280 维），必须整体存储与比较。面对边缘设备部署、大规模检索管线或严格延迟预算时，只能"一模型一预算"或事后降维（可能破坏已学到的语义结构）。
- **关键空白**：Matryoshka Representation Learning（MRL）已在 2D 视觉、语言、多向量检索、多模态生成、高斯泼溅等场景验证有效，但**在多模态 3D 表示学习中完全未被探索**。
- **难点**：3D 点云嵌入既要保持几何结构，又要与冻结的图像/文本嵌入对齐；前缀截断在 3D 中可能不成比例地删除对检索与识别关键的局部几何线索；多尺度对比监督会引入相互竞争的约束。
- **整体意义**：提出 3D-MRL，用**单一编码器**在任意前缀长度下输出高质量嵌入，无需重训练即可在精度—效率之间连续权衡，为预算感知的可扩展 3D 理解提供基础。

## 2. 方法论

### 2.1 核心思想
- 让 3D 编码器 EP 产生的表示满足：**低维前缀保留粗粒度类别语义，高维前缀逐步精化几何与结构细节**；所有前缀都是同一向量的严格嵌套子集。
- Matryoshka 目标**只施加于 3D 编码器**，图像与文本编码器（CLIP）全程冻结，提供固定多模态目标。

### 2.2 关键技术细节
- **问题设定**：数据集为三元组 S = {(Pᵢ, Iᵢ, Tᵢ)}，P 为点云，I 为渲染图像，T 为 BLIP/Azure GPT-4 生成的文本。f_P = E_P(P)，f_I = E_I(I)，f_T = E_T(T)，全部 ℓ2 归一化到单位超球面。
- **嵌套维度集**：D = {d₁,…,d_K}，1 ≤ d₁ < … < d_K = D。最大维度对齐 CLIP 的 D = 1280，基维度 d₁ = 10，采用**对数（几何级数）调度**：D = {10, 20, 40, 80, 160, 320, 640, 1280}，共 K = 8 个嵌套尺度，即 O(log D) 个监督点。
- **参数无关几何截断**：对任意 d_k，子嵌入 f_P^{d_k} = f_P[1:d_k]（取前 d_k 个连续坐标），随后**重新归一化**为单位范数以保持方向一致性；嵌套约束保证 f_P^{d_a} ⊂ f_P^{d_b}（d_a < d_b）。
- **多尺度对比对齐**：由于冻结 CLIP 编码器无法动态调整内部结构，对图像/文本目标同样施加相同的前缀切片并重新归一化，得到 f_I^{d_k}、f_T^{d_k}。
- **损失函数**：在每个尺度 d_k 上使用 InfoNCE（温度 τ > 0），余弦相似度 ⟨·,·⟩：
  - L_NCE(f^{d_k}_{M1}, f^{d_k}_{M2}) = −(1/n) Σᵢ log [ exp(⟨f^{d_k}_{M1,i}, f^{d_k}_{M2,i}⟩/τ) / Σⱼ exp(⟨f^{d_k}_{M1,i}, f^{d_k}_{M2,j}⟩/τ) ]
  - 总目标：min Σ_{k=1}^{K} λ_k · [ L_NCE(W^{d_k}·f_P^{d_k}, f_I^{d_k}) + L_NCE(W^{d_k}·f_P^{d_k}, f_T^{d_k}) ]，默认 λ_k = 1，联合优化 3D 编码器参数 θ_P 与各尺度线性分类器 {W^{d_k}}。
- **高效 vs 非高效模式**：
  - 非高效（Efficient = False）：每个尺度保留独立投影矩阵 {W^{d_k}}，W^{d_k} ∈ R^{d_k×d_k}。
  - 高效（Efficient = True，默认）：**去除尺度专用投影头**，仅靠参数无关的前缀截断 + 共享投影参数，大幅降低参数开销。
- **学到的表示两大性质**：
  1. **嵌套语义一致性**：f_P^{d_i} = (f_P^{d_j})[1:d_i]，低维语义在所有更大尺度上被保留。
  2. **渐进式表示精化**：维度增加带来额外自由度，可编码小嵌入无法表达的信息，且不丢弃低维已学内容。
- **下游使用**：
  - 零样本分类：跨所有 K 个尺度聚合相似度 s(c|Pᵢ) = Σ_k α_k ⟨f_P^{d_k}, f_T^{d_k,c}⟩（默认均匀权重），取 argmax。
  - 少样本：冻结嵌套嵌入，在每个尺度上训练线性分类器，扫描 d_k 得到完整精度—紧凑度曲线，无需重训练或改架构。

  - 消融：高效 vs 非高效 MRL（Table 6）、三种嵌套维度调度 full/linear/log-based（Table 7）；补充材料另有多尺度数量与模态对齐消融。
- **充分性与客观性评价**：
  - **优点**：覆盖零样本、少样本、真实扫描、检索、效率与消融，维度扫描（10→1280）系统完整；预训练设置与评价协议严格对齐 OpenShape/CLIP²，具备可比性；少样本报告 10 次试验的均值与标准差，统计上较规范。

## 6. 主要结论与发现

- **首个把 MRL 引入多模态 3D 预训练的框架**，单一编码器即可在任意前缀长度输出可用表示，无需重训练或维护多个编码器。
- **零样本识别**：Ensembled 预训练下，Objaverse-LVIS Top-1 由 OpenShape-PointBERT 的 46.8% 提升到 3D-MRL-PointBERT 的 **50.9%**（+4.1%，相对 ULIP +24.1%）；ModelNet40 达 85.8%（比 OpenShape 高 +1.4%）；ScanObjectNN 表现"尚可但相对偏弱"，说明合成到真实的零样本迁移仍然困难。
- **精度—效率前沿**：匹配预算下 640D 达 42.5%（vs OpenShape 40.2%），1280D 达 50.9%（vs 46.6%）；对事后 PCA 压缩的鲁棒性显著更强（40/80/160D 分别为 27.3/43.3/50.0%，OpenShape 仅 14.7/29.5/40.8%）。
- **检索效率**：320D 相比 1280D 存储降低 4×（225.61→56.40 MB），CPU 检索延迟降低 4.1×（5.11→1.26 ms）。
- **少样本**：Ensembled + PointBERT 下，在 4 个设置中的 3 个超过 OpenShape（5-way 20-shot +2.2%、10-way 10-shot +0.6%、10-way 20-shot +1.4%），且类别数更多（10-way）时增益更明显，说明嵌套结构本身已使语义线性可分。
- **真实场景**：ScanNet 上 **640D 取得最佳 47.0%**（超过 OpenShape 1280D 的 45.6% 和 CLIP² 的 38.5%），说明含噪、遮挡、部分观测的真实场景中，中等维度反而在语义抽象与几何特化之间取得更好平衡；且不同类别在不同粒度达到各自最优。
- **层级检索行为**：低维前缀恢复宽泛语义（如"车辆"），高维逐步收敛到细粒度几何/实例匹配（如特定摩托车的车架、轮组与颜色）；文本→3D 检索在相同 1280D 下比 OpenShape 更贴合"人体工学办公椅"这类细粒度描述。
- **消融结论**：参数无关几何截断（Efficient = True）相比独立投影头仅有近乎可忽略的精度损失（Objaverse-LVIS Top-3 21.6% vs 22.1%；ModelNet40 Top-1 71.5% vs 71.8%），却显著降低参数开销；**对数调度**优于 full 与 linear 调度（ModelNet40 71.8% vs 70.6% / 69.8%），起到有效的多尺度优化正则作用。

## 7. 优点

- **问题定位精准**：把"固定维度嵌入导致部署不灵活"这一现实瓶颈与 MRL 这一成熟技术结合，填补了 MRL 在 3D 多模态表示学习中的空白，动机清晰、贡献界定明确。
- **设计简洁高效**：核心机制是**参数无关的前缀截断 + 重新归一化**，只在训练时使用轻量尺度专用投影；相比传统多尺度方法（RD→R^{d_k} 的独立投影头）参数开销大幅降低，且截断在推理时零成本。
- **训练与推理一致性好**：把嵌套结构与跨模态对比预训练"从训练一开始就耦合"，而非事后套用 MRL，使降维成为学习到的空间属性，这一点在概念上优于 post-hoc 降维。
- **效率分析扎实**：同时给出匹配预算精度、PCA 压缩鲁棒性、存储占用、CPU 延迟与 QPS，构成完整的部署视角证据链。
- **维度调度消融有价值**：系统比较 full / linear / log-based 三种调度，论证 O(log D) 尺度既提供密集的低维监督又避免过参数化，具有方法论迁移价值。
- **现象观察有洞见**：揭示"低维=宽泛语义、高维=几何细节"的层级组织，以及不同类别在不同粒度最优、真实场景中 640D 反超 1280D 等非平凡发现，对后续工作有启发
