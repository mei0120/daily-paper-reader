## 摘要
开放词汇分割能够为无人机提供丰富的语义感知，但逐帧预测在重复观测和视角变化下可能在时间上不一致。我们提出 PerSeM，一种无需训练的持久语义记忆框架，用于长时程开放词汇无人机建图。PerSeM 将逐帧语义观测与持久的世界空间体素相关联，并构建基于多数投票的语义记忆，再通过保留历史的空间细化、信任感知回放和上下文引导验证对其进行保守细化。在 Forest 和 UAVScenes 基准上的实验表明，持久 3D 记忆在语义正确性和时间稳定性上相较逐帧预测带来显著提升。在这一强持久记忆基线之上，PerSeM 还提供了一致的额外改进，在评估的全部五个 UAVScenes 序列上同时提升了语义准确性和时间稳定性。使用独立于最终 PerSeM 预测所识别区域的分析进一步表明，这些增益集中在语义困难且时间不稳定的区域，在这些区域中，基于多数投票的记忆最可能仍保持不确定。这些结果表明，持久 3D 聚合为长时程语义建图提供了坚实基础，而对不确定记忆状态的保守细化无需重新训练或额外神经网络推理即可带来额外改进。

## Abstract
Open-vocabulary segmentation enables rich semantic perception for UAVs, but frame-wise predictions can remain temporally inconsistent across repeated observations and changing viewpoints. We present PerSeM, a training-free persistent semantic memory framework for long-horizon open-vocabulary UAV mapping. PerSeM associates frame-wise semantic observations with persistent world-space voxels and constructs a majority-based semantic memory, which is conservatively refined through history-preserving spatial refinement, trust-aware replay, and context-guided verification. Experiments on the Forest and UAVScenes benchmarks show that persistent 3D memory provides substantial gains in semantic correctness and temporal stability over frame-wise predictions. Beyond this strong persistent-memory baseline, PerSeM provides consistent additional improvements, improving both semantic accuracy and temporal stability across all five evaluated UAVScenes sequences. Analysis using regions identified independently of the final PerSeM predictions further shows that these gains are concentrated in semantically difficult and temporally unstable regions, where majority-based memory is most likely to remain uncertain. These results demonstrate that persistent 3D aggregation provides a strong foundation for long-horizon semantic mapping, while conservative refinement of uncertain memory states can provide additional improvements without retraining or additional neural-network inference.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：开放词汇语义分割与大视觉基础模型显著提升了无人机（UAV）图像的语义理解能力，支持自主导航、主动感知、可通行性推理与避障规划等下游任务，且无需任务特定重训练。
- **核心问题**：UAV 视频流中的逐帧语义预测在视角变化、稀疏重访和视觉歧义场景下存在严重的**时间不稳定性**。分析表明，语义波动集中在一小部分反复出现的场景区域，逐帧预测无法在世界空间中维持持久语义。
- **现有方法局限**：主流时序一致性方法（MaskProp、STCN、AOT、XMem、Video K-Net 等）主要在 2D 图像或视频域做时序平滑、特征对应与短期记忆，改善的是相邻帧的视觉连贯性；但机器人交互发生在**持久 3D 环境**中，语义信息需跨多次观测与视角变化累积和维持。
- **关键观察**：持久世界空间聚合本身就能解决大部分帧级不稳定性——重复观测可为多数复现区域建立可靠语义分配。**剩余挑战不是全局语义聚合，而是识别并修正不确定的记忆状态，同时不破坏稳定分配。**
- **整体含义**：论文提出 PerSeM——一个免训练的持久语义记忆框架，作为持久 3D 记忆之上的**保守细化层**，选择性重访不确定状态，在保留稳定分配的同时利用有支持的证据修正残余错误。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
- 将逐帧开放词汇语义输出视为**语义观测**，与持久世界空间体素关联，累积观测历史。
- 先构建**多数投票持久体素记忆**作为语义锚点，再通过三个保守阶段细化：历史保留空间细化 → 信任感知证据回放 → 上下文引导验证。
- 密集图像空间重投影**仅用于评估与可视化**，不修改持久记忆。

### 2.2 持久体素记忆构建
- 给定逐帧语义预测、深度估计和相机位姿，将有效语义观测反投影到世界坐标，关联到体素化 3D 表示。
- 同一帧内分配到同一体素的观测通过多数投票聚合为单次语义观测，置信度由帧内体素语义一致性给出。
- 每个体素 \(v\) 维护时间有序观测历史 \(H_v = \{(c_i, s_i, t_i)\}_{i=1}^{N_v}\)，其中 \(c_i, s_i, t_i\) 分别为语义标签、置信度和帧索引。
- 累积类别证据：\(h_v(c) = \sum_{i=1}^{N_v} s_i \mathbf{1}[c_i = c]\)，初始记忆标签为 \(c_M(v) = \arg\max_c h_v(c)\)。
- 观测历史不足的体素保留该分配；复现体素将累积证据和有序历史暴露给后续细化阶段。

### 2.3 历史保留空间细化
- 将累积类别证据归一化为概率 \(p_v(c) = h_v(c) / \sum_{c'} h_v(c')\)。
- 计算空间邻域 \(N(v)\) 上的平均历史分布 \(q_v(c) = \frac{1}{|N(v)|}\sum_{u \in N(v)} p_u(c)\)。
- 软组合：\(\tilde{p}_v(c) = (1-\eta)p_v(c) + \eta q_v(c)\)，\(\eta\) 控制邻域历史贡献。
- 历史保留锚点：\(c_H(v) = \arg\max_c \tilde{p}_v(c)\)。该阶段修改的体素**受保护**，不被后续信任回放覆盖。

### 2.4 信任感知证据回放
- 仅对历史锚点仍保留多数记忆分配的复现体素执行。
- 按顺序回放观测，每个观测 \(o_i\) 的信任权重：\(w_i = s_i \exp(-\lambda_v \rho(c_i)) \exp(-\lambda_s g_i) \exp(-\lambda_t \Delta t_i)\)，其中 \(\rho(c_i)\) 为类别波动性，\(g_i\) 为与当前主导信念的分歧，\(\Delta t_i\) 为与前一次观测的时间间隔。
- 回放时累积证据指数衰减并更新：\(e_i = \gamma e_{i-1}\)，\(e_i(c_i) \leftarrow e_i(c_i) + w_i\)，\(\gamma\) 控制证据衰减。
- 回放产生时间提案 \(c_T(v) = \arg\max_c e(c)\)。
- **回放边际门控**：若提案与多数记忆标签不一致，仅当其回放证据超过多数标签证据的边际 \(\tau_{\text{replay}}\) 时才进一步考虑；否则保留历史锚点。

### 2.5 保守上下文验证
- 通过回放边际的提案还需满足空间支持：
  - 硬上下文支持：\(S_{\text{hard}}(v,c) = \frac{1}{|N(v)|}\sum_{u \in N(v)} \mathbf{1}[c_M(u)=c]\)
  - 历史上下文支持：\(S_{\text{hist}}(v,c) = \frac{1}{|N(v)|}\sum_{u \in N(v)} p_u(c)\)
- 仅当两个上下文边际均超过阈值 \(\tau_{\text{context}}\) 时，提案才替换多数分配：\(S_{\text{hard}}(v,c_T) - S_{\text{hard}}(v,c_M) > \tau_{\text{context}}\) 且 \(S_{\text{hist}}(v,c_T) - S_{\text{hist}}(v,c_M) > \tau_{\text{context}}\)；否则保留历史锚点。
- 该双重验证将信任修正限制在时间与空间证据一致的位置。

### 2.6 密集语义重投影
- 最终体素标签通过深度、内参和位姿重投影到每个相机视图，用于与帧级真值比较、时序稳定性分析和定性可视化，不修改持久记忆。

## 6. 主要结论与发现

- **持久 3D 聚合是主要增益来源**：在 Forest 和 UAVScenes 上，持久 3D 记忆相比逐帧预测在语义正确性和时序稳定性上均有大幅提升，说明重复世界空间观测已解决大部分语义不稳定性。
- **PerSeM 在强基线上提供一致额外改进**：
  - Forest：PA 83.44 → 84.02，mIoU 39.66 → 39.84，Flicker 24.39 → 23.00。
  - UAVScenes：PA 81.21 → 81.41，mIoU 41.50 → 41.90，Flicker 7.27 → 6.90。
  - PerSeM 是唯一在宏平均层面于两个 benchmark 上同时改善三项指标（相对 Raw3D Majority）的持久记忆变体，且 mIoU 和 Flicker 改进在全部五个 UAVScenes 序列上保持一致。
- **增益集中在困难区域**：在独立识别的困难区域中，PA 增益从整体 +0.20 提升至边界 +0.38、困难核心 +0.53、高切换区域 +1.22；Flicker 降低从 0.37 提升至 0.80、0.92、1.80。高切换区域仅占 8.28% 像素，但时序稳定性改善最显著。
- **信任回放不是均匀有益的估计器**：单独使用信任回放会降低所有指标；在 HKisland01 上加入信任回放可恢复 +0.50 PA 和 +0.86 mIoU（但 Flicker 增加 0.97），而在 HKairport01 上反而降低 PA/mIoU 并增加 Flicker。因此信任回放应作为受上下文验证约束的残余恢复通路，而非独立标签决定机制。
- **无需重训练或额外神经网络推理**，即可实现不确定记忆状态的保守修正。

## 7. 优点

- **问题定位清晰**：将长时程开放词汇 UAV 建图的关键挑战从“全局聚合”重新定义为“识别何时应重新考虑已建立的语义记忆”，并聚焦残余不确定状态。
- **方法设计保守且合理**：历史保留空间细化不丢弃体素累积证据；信任回放仅作为修正提案，受回放边际和双重上下文验证约束；已被空间细化修改的体素受保护，避免过度修正。
- **免训练、轻量**：不需要额外神经网络推理或重训练，细化开销相对总流程很小（Forest +0.13%，UAVScenes +8.4%），峰值内存较低。
- **实验分析扎实**：
  - 困难区域定义独立于最终 PerSeM 预测，避免评估偏差。
  - 组件消融清楚揭示各模块作用（Context Only 有益，Trust Only 有害，History Blend 小幅有益）。
  - 场景依赖分析诚实地展示信任回放的利弊，不夸大单一组件贡献。
  - 控制变量严格，所有持久记忆方法共享相同观测、几何和体素化。
- **结论与动机一致**：增益集中在语义困难和时间不稳定区域，支持“选择性细化”而非“全局重写”的设计理念。

## 8. 不足与局限

- **继承多数记忆的固有缺陷**：
  - 稳定但错误的多数分配可能无法被修正。
  - 稀疏或少数类别可能被主导观测吸收，对安全关键类别不利。
  - 固定历史混合可能偏向主导局部语义，难以保留稀有或空间小类别。
- **手工设计的信任与上下文线索**：信任和上下文线索为手工设计；组件分析表明可靠性线索单独使用不足，必须依赖上下文约束才能避免不稳定修正。
- **顺序敏感性**：顺序信任回放对观测顺序和采样密度敏感，缺乏顺序鲁棒的时序加权机制。
- **几何依赖**：假设深度和相机位姿准确；位姿噪声分析未覆盖长期定位漂移或相关几何误差的全部影响。
- **分类法不匹配**：开放词汇模型预测与闭集 benchmark 分类法之间存在不匹配，细粒度与分组 UAVScenes 评估之间的差距反映了这一问题。
- **实验覆盖有限**：仅在 Forest 和 UAVScenes 上验证，数据集和序列数量有限；未与其他开放词汇建图系统进行端到端对比；未涉及动态场景、自适应历史混合、类别感知保留、学习型不确定性细化等。
